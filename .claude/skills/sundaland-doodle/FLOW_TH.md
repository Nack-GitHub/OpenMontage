## ขั้นที่ 1 · วางเรื่อง (beat sheet)
Claude แบ่งเรื่องเป็นช็อต แต่ละช็อตมี: ข้อความ/เสียงพากย์ + ตัวละครทำอะไร + เลือกวิธีทำ

- **แบบสลับท่า (sprite):** ใช้เมื่อต้องการท่าเฉพาะหรือถือของ เช่น นั่งพิมพ์แล็ปท็อป กางร่ม อ่านหนังสือ ถือกล่อง ตัวละครขยับได้ทั้งตัว (เด้ง กระโดด โยก เลื่อน) แต่แขนขาไม่ขยับ
- **แบบ mocap (AnimatedDrawings):** ใช้เมื่ออยากให้แขนขาขยับจริง เช่น ทักทาย กระโดดดีใจ กระโดดตบ เต้น เชียร์ แต่มีให้เลือกแค่ท่าที่มีอยู่ (ยังไม่มีท่าเดิน)

## ขั้นที่ 2 · วาดใน Gemini (งานของคุณ)
Prompt ทั้งหมดอยู่ใน [`prompts/gemini_prompts.md`](prompts/gemini_prompts.md):
- **A · ชีตท่าทาง** ใช้ทุกตอน 6–8 ท่าต่อภาพ
- **B · ท่า rig สำหรับ mocap** ตัวเดียว กางแขนกางขาแบบ A-pose วาดครั้งเดียวต่อตัวละคร
- **C · ชีตพร็อพ** เช่น เรือ ตู้คอนเทนเนอร์ ลูกโลก เหรียญ
- **D · ตัวละครตัวที่ 2** เปลี่ยนเป็นเสื้อสีฟ้า

**สำคัญมาก:** แนบภาพ `template/examples/style-reference-sheet.jpg` ไปกับทุก prompt เพื่อให้สีส้ม ขนาดหัว และน้ำหนักเส้นเหมือนเดิมทุกตอน

เช็กก่อนส่ง:
- [ ] ตัวละครแต่ละท่าห่างกัน มีช่องขาวคั่น ไม่แตะกัน
- [ ] พื้นขาวล้วน ไม่มีเงา ไม่มีลายกระดาษ
- [ ] ไม่มีตัวหนังสือที่ไม่ได้ขอ
- [ ] ภาพใหญ่ อย่างน้อย 2000 px ด้านยาว
- [ ] (ท่า rig) มีตัวเดียว แขนไม่ชิดหัวหรือตัว ขากาง

ส่งไฟล์ให้ Claude หรือวางไว้ที่ `projects/<ชื่อตอน>/source/`

## ขั้นที่ 3 · ตัดภาพ (Claude)
ตัดแต่ละท่าเป็น PNG พื้นใส แล้วส่งภาพเช็กบนพื้นตารางหมากรุกให้คุณดู:
- หัว หน้าหนังสือ กระดาน ต้องเป็นสีขาวทึบ ไม่ทะลุ
- ชิ้นเล็ก (โน้ตดนตรี zzz ประกาย) ต้องอยู่กับตัวที่ถูก ถ้าผิด Claude แก้ด้วย `overrides.json`

## ขั้นที่ 4 · ทำแอนิเมชัน (Claude)
**แบบสลับท่า:** ใช้ template `sprite-scene.html` สลับท่าแบบเด้ง หายใจ กระโดด เลื่อนข้ามจอ จอสั่น ฝนตก และเขียนชื่อช่องบนป้ายได้

**แบบ mocap:**
1. วางข้อต่อ 16 จุดบนท่า rig แล้วส่งภาพข้อต่อให้คุณดู
2. เรนเดอร์ท่า mocap แบบเต็มความยาว (dab, กระโดด, กระโดดตบ, เต้น)
3. เลือกช่วงที่สวยที่สุดของแต่ละท่า แล้วตัดเป็นคลิปสั้น
4. ประกอบกับข้อความและพร็อพใน `ad-scene.html`

ทั้ง 2 แบบผสมกันในคลิปเดียวได้

## ขั้นที่ 5 · เช็กและเรนเดอร์ (Claude)
lint → ส่ง contact sheet ให้ดู → เรนเดอร์ MP4 1080p 30fps → สุ่มดู 1 เฟรมต่อวินาทีก่อนส่ง

## ข้อจำกัด
- แบบสลับท่า: แขนขาไม่ขยับ
- แบบ mocap: มีแค่ท่าที่มีอยู่ ยังไม่มีท่าเดิน เส้นจะยืดนิดหน่อยตอนขยับแรงๆ และต้องวางข้อต่อใหม่ทุกครั้งที่ใช้ภาพ rig ใหม่
- ความคมชัดขึ้นกับขนาดภาพจาก Gemini

## ถ้าอยากได้ท่าที่ยังไม่มี
- **ท่าเดิน:** ให้ Gemini วาดเฟรมเดิน 3–4 เฟรมต่อเนื่อง (เท้าซ้ายก้าว → ยืนตรง → เท้าขวาก้าว) แล้ว Claude เรียงเป็น sprite
- **ท่า mocap ใหม่:** หาไฟล์ BVH จากคลัง CMU (ฟรี) แล้ว Claude ทำ retarget ให้
