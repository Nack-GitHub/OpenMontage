# Prompt สำหรับตอนถัดไป (format เล่าเรื่อง)

## แบบสั้นที่สุด (ใช้ skill)

```
/sundaland-story Palembang oil raid 1942
```

ใส่ชื่อเหตุการณ์หรือไอเดียได้เลย หรือวางลิงก์ YouTube ของคลิปที่อยากเอามาปรับให้เข้ากับช่องก็ได้ เช่น
`/sundaland-story https://www.youtube.com/watch?v=...` แล้ว agent จะหาเหตุการณ์ในภูมิภาคที่เข้ากับเรื่องนั้นมาเสนอ 3 แบบ

## แบบเต็ม (ใช้กับ agent อื่น หรือไม่อยากใช้ skill)

```
ทำคลิปให้ช่อง The Sundaland แบบ format เล่าเรื่อง (story) หัวข้อ "<เหตุการณ์>"
อ่าน .claude/skills/sundaland-story/SKILL.md และ FORMAT.md ก่อน แล้วใช้โค้ดใน template/

- คลิป 16:9 ยาว 9–11 นาที บรรยายภาษาอังกฤษ ตอบผมเป็นภาษาไทย
- เหตุการณ์เดียวในภูมิภาค Sundaland/อาเซียน เล่าแบบนาทีต่อนาที 3 องก์ (ทำไมต้องที่นี่ → คืนนั้น → ผลที่ตามมา)
  พร้อม hook ที่มองเรื่องเดิมในมุมใหม่ผ่านเศรษฐกิจและภูมิศาสตร์
- ภาพผสมกัน: แผนที่ดาวเทียมของช่อง, แผง HUD ตัวเลข, รูปจริงจาก Wikimedia, การ์ตูน doodle ราว 20–25%
  (การ์ดกระดาษบนแผนที่ / ฉากหลังสีเทียน / สติกเกอร์เดินบนแผนที่), เส้นทางเรือต้องอยู่ในทะเล,
  เส้นทางบินมีเครื่องบิน 3D
- เสียง: Brian เป็นผู้บรรยาย + เสียงตัวละครที่ไม่ระบุชื่อ 2–4 เสียง (ห้ามแต่งคำพูดให้บุคคลจริง)
- จ่ายเงินได้แค่ ElevenLabs TTS ภาพการ์ตูนผมวาดเองใน Gemini app ห้ามเรียก Gemini/Imagen/Veo/Lyria API
- ให้อนุมัติทีละขั้น: proposal 3 แบบ → เลือกเสียง → สคริปต์ → scene plan + รายการภาพที่ต้องวาด →
  ภาพนิ่งทุกฉาก → คลิปเต็ม → thumbnail 3 แบบ → แพ็ก publish (ห้ามอัปโหลดเอง)
```

## สิ่งที่คุณต้องทำเองระหว่างทาง

1. **อนุมัติ** proposal, เสียงตัวละคร, สคริปต์ และ scene plan
2. **วาดภาพใน Gemini app** ตาม prompt ที่ agent ให้ ปกติคือ:
   - ตัวละครฝ่ายละ 1 แผ่น (2–3 ฝ่าย)
   - อุปกรณ์ 2–3 แผ่น
   - ฉากหลังสีเทียน 3–6 ภาพ
   
   พิธีกรเสื้อส้มมีพร้อมแล้ว ไม่ต้องวาดใหม่
3. **เปิด Claude in Chrome** ไว้ ถ้าจะให้ agent หาเพลงจาก YouTube Audio Library ใน Studio ของช่อง
4. **ตรวจคลิปเต็ม** แล้วอัปโหลดเองแบบ **Private** ก่อน

## ก่อนเริ่มควรเช็ก

- ไดรฟ์ D: ว่างอย่างน้อย 10 GB (ไฟล์ชั่วคราวตอนเรนเดอร์ไปลงที่ D:)
- ลบโฟลเดอร์ `remotion-webpack-bundle-*` เก่าใน %TEMP% ถ้าไดรฟ์ C: ใกล้เต็ม
- `ELEVENLABS_API_KEY` และ `PIXABAY_API_KEY` ยังอยู่ใน `.env`
