## แบบเต็ม (ถ้าไม่อยากใช้ skill หรือใช้กับ agent อื่น)

```
ทำคลิปให้ช่อง The Sundaland หัวข้อ "20 Facts About <ประเทศ> That Sound Fake (But Aren't)"
ใช้ format เดียวกับโปรเจกต์ projects/thailand-sounds-fake ทุกอย่าง (อ่าน .claude/skills/sundaland-facts/SKILL.md ก่อน)

- คลิปยาว 16:9 ยาว 8–10 นาที บรรยายภาษาอังกฤษ ตอบผมเป็นภาษาไทย
- แนวช่อง: การค้า ภูมิศาสตร์ เศรษฐกิจ ห้ามข้อพิพาทที่ยังไม่จบและการเมืองภายใน
- แบ่ง 3 องก์ The Land / The Water / The Money ข้อ 1 ปิดท้ายให้โยงเข้า Sundaland หรือภูมิภาคถ้าเป็นไปได้
- สไตล์แผนที่แบบคลิป Malacca: ลูกโลกมีเมฆ, กล้องตามเรือคอนเทนเนอร์ 3D มุมเอียง, ประเทศเด้งเป็นรูปทรงสีทึบ,
  เส้นชี้ต้องมีของวิ่งตาม, จังหวัดเด้ง + หมุดติ๊ก, ข้อมูลตัวเลขเป็นแอนิเมชันไม่ใช่กราฟแท่ง
- โลโก้ + คำใต้โลโก้ ECONOMY GEOGRAPHY, ลายน้ำมุมขวาล่าง, ตอนจบเป็นลูกโลกมีเมฆ + ป้ายโลโก้ แล้ว end card กด Subscribe + กระดิ่ง 8 วินาที
- จ่ายเงินได้แค่ Google TTS (Chirp3-HD Orus) ห้ามใช้ Veo / Imagen / Lyria; ภาพใช้ Pixabay + Wikimedia + NASA ฟรีเท่านั้น
- ให้อนุมัติทีละขั้น: แผน → สคริปต์ → scene plan → ภาพนิ่งทุกฉาก → คลิปเต็ม → thumbnail 3 แบบ → แพ็ก publish (ห้ามอัปโหลดเอง)
```

## เรื่องที่ควรบอกเพิ่มถ้าต้องการต่างจากเดิม

- ภาษาบรรยาย (ค่าเริ่มต้นคือภาษาอังกฤษ)
- จำนวนข้อหรือความยาว (ค่าเริ่มต้นคือ 20 ข้อ, 8–10 นาที)
- ถ้าอยากทำเป็น Short แนวตั้ง ให้บอกตั้งแต่ต้น (skill นี้ออกแบบมาสำหรับคลิปยาว)

## ก่อนเริ่มควรเช็ก

- ดิสก์ว่างอย่างน้อย 5–10 GB
- `PIXABAY_API_KEY` ยังอยู่ใน `.env`
